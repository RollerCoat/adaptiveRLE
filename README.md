# Java Binary Run-Length Encoding (RLE)

## Description
A self-written binary Run-Length Encoding (RLE) compression algorithm implemented in Java.

The project includes:
- A compression algorithm (`Compress`)
- A decompression algorithm (`Decompress`)
- A testing and benchmarking system (`Test`)

## Features
- Binary data compression
- Adaptive selection between compressed and uncompressed representation
- Data integrity testing through decompression
- Runtime benchmarking for compression and decompression

## Purpose
This project was created to learn more about algorithms, data compression, Java programming, and performance measurement.

## Status
Currently functional. Further optimizations and improvements may follow.
